How it was built

Nine stages, each a pure function over the previous stage's file on disk — resumable after a crash, idempotent on re-run. The extractor (Gemini) can never cite a URL it did not fetch: citations are constrained to an enum of this run's document ids, then re-validated against the fetch log. An independent critic on a different vendor (via OpenRouter) reviews each record so it can't share the extractor's mistakes.

— rows were routed to a human review queue — unknown auth or gate, low confidence, or a flagged ambiguous entity. That routing is the deliverable, not an apology: the job is to move apps through approval, and knowing which ones need a person is step one.
